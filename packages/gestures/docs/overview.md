# gestures

The touch gestures Spliteco and Tripeco share (tripeco TR-5): the tab pager, the row swipe that reveals or fires, hold, pull to refresh, dragging a sheet away, the edge swipe back and the slider. They are pure rules plus small React helpers, first copied from Cookpool's PW-7 and PW-8 for Spliteco (spliteco-calm SL1) and moved here so there is one copy for both apps (risk SL-A).

A workspace package built by the turbo pipeline. It deploys nothing on its own.
