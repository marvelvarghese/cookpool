# spliteco-ui

Spliteco's money screens as shared, themeable React parts and their logic (cookpool-spliteco SE3, design §0.4): the balance card, the "why" list, add a bill and Settle up (UPI with `upi://pay` then "I paid", or cash, or bank). Cookpool's Money tab draws them in the revamp's look; the Spliteco app in Deep ocean.

A workspace package built by the turbo pipeline. It deploys nothing on its own.
