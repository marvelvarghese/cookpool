# spliteco-ui-tests

The shared Spliteco money screens' tests (packages/spliteco-ui, cookpool-spliteco SE3), run on dev: the balance card, the why list, add a bill and Settle up — their logic, and the parts rendered to markup with a theme, which must hold no styling of their own.

A workspace package built by the turbo pipeline. It deploys nothing on its own.
