# spliteco-web-tests

The Spliteco app's tests (cookpool-spliteco SE1), run on dev: the Add expense form's request builder for all six splits, the itemized panel's values, money parsing and formatting, Activity's words, the Insights chart maths, export names and the `/api` forwarder.

A workspace package built by the turbo pipeline. It deploys nothing on its own.
