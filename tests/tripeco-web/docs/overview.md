# tripeco-web-tests

The Tripeco app's tests (tripeco TR-5), run on dev: the Spliteco sign-in links and handoff targets, money and km formatting, ride rows, the tab addresses, the Asphalt & lime tokens, and the `/api` forwarder.

A workspace package built by the turbo pipeline. It deploys nothing on its own.
